# GP Technologies - High-Performance Digital Solutions

GP Technologies is a Dubai-based SME driving digital excellence through strategic innovation, fully aligned with the UAE National AI Strategy 2031.

## Project Structure

This project is built with:

- **Vite**: Build tool and development server.
- **TypeScript**: Static typing for enhanced developer experience.
- **React**: Library for building user interfaces.
- **shadcn/ui**: Reusable components built with Radix UI and Tailwind CSS.
- **Tailwind CSS**: Utility-first CSS framework.
- **Framer Motion**: Animation library for smooth transitions.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd gp-technologies-elevate

# Install dependencies
npm install
```

### Development

```sh
# Start the development server
npm run dev
```

### Production Build

```sh
# Create a production build
npm run build

# Preview the production build
npm run preview
```
